# Contributing guidelines

> [!IMPORTANT]
> No LLM / No generative AI policy. This means:
>
> - Do not generate issues using LLMs.
> - Do not use LLMs for patches / pull requests.
> - Do not submit LLM-generated comments on the issue tracker.

If you have found a bug in **yadg** or would like a feature added, please open an issue, ideally attach some example or test files, and in case of a bug, copy-paste the **yadg** output. We can then either guide you towards writing your own fix, or implement the fix directly. 

Further contributing guidelines targeted at more experienced developers are available in the [Developer documentation](https://dgbowl.github.io/yadg/main/devdocs.html).
